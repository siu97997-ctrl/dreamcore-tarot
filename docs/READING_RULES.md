# MVP Tarot Reading Rules

运行时规则位于 `data/reading_rules.json`。

## 默认牌阵

- **看清这件事**：当前核心／未被看见的影响／现在最有帮助的行动。
- **接下来会怎样**：当前能量／发展趋势／可改变趋势的行动。

两个牌阵都使用三张牌，不重复抽牌，开启正逆位；第一版逆位概率为 35%。

## 解读原则

1. 先判断用户在问感情、事业、自我还是趋势。
2. 每张牌必须通过所在牌位解释，不能只复述单牌数据库。
3. 找出主导牌，再检查花色、元素、重复数字、宫廷牌和逆位集中情况。
4. 当牌意冲突时明确呈现张力，不忽略不方便解释的牌。
5. 最终形成一条完整故事，并给出一个可执行行动。
6. 只拓展一个问题，然后自然结束。

## 趋势与边界

- 可以直接回答趋势，但使用“目前更像是”“如果现状不变”等条件式表达。
- 不把牌面当作他人内心的确定事实。
- 不进行医疗、法律或投资结论；出现即时危险时停止占卜式表达，优先现实安全支持。

## 核心逻辑

- `src/tarot-engine.mjs`：问题路由、抽牌、正逆位、牌位绑定、组合分析和 AI 解读简报。
- `scripts/demo_tarot_reading.mjs`：命令行演示，不调用 AI。
- `tests/tarot-engine.test.mjs`：固定种子、无重复抽牌和问题路由测试。

演示命令：

```bash
node scripts/demo_tarot_reading.mjs "如果现状不变，这段关系接下来会怎样？" 42
```
