# Tarot Data v0.1 使用说明

## 本版范围

- `data/tarot_cards.json` 包含完整 78 张牌的稳定 ID、双语牌名、分类、序号、元素、图片路径和正逆位内容槽位。
- 22 张大阿卡纳已从现有只读素材复制并规范命名。
- 当前工作区未发现 56 张小阿卡纳和牌背文件，因此仅预留准确路径，并标记为 `pending_import`。
- 本阶段不包含前端、抽牌算法或 LLM 调用代码。

## 数据约定

- `id` 是程序主键，不随展示文案变化。
- `slug` 用于检索和文件命名。
- `asset_status`：`ready` 表示文件已存在；`pending_import` 表示等待素材导入。
- `editorial_status`：当前统一为 `skeleton`；牌义内容审核完成后再改为 `reviewed`。
- `upright` / `reversed` 均保留 `core`、`love`、`career`、`self`、`trend`、`advice` 六个字段。
- `trend` 用于趋势预测；`self` 用于自我探索。两者并存，不把塔罗缩减为纯心理投射或绝对宿命预测。

## AI 与 Reading 约束

- AI 人格：神秘、直接、有朋友感。
- 牌义事实来自数据库；AI 负责结合问题、牌阵位置和牌间关系进行表达。
- MVP Reading 固定流程：提问 → 抽牌 → 解读 → 只拓展一个更深的问题 → 结尾。
- 趋势判断使用“当前能量与行为延续下更可能出现”的表达，不写成不可改变的绝对结论。

## 重建方式

运行 `node scripts/build_tarot_library.mjs` 可依据脚本中的卡牌清单重新生成数据库、素材清单并重新复制大阿卡纳。注意：重建会覆盖两个 JSON 文件中的手工牌义，因此开始填充内容后，应先调整构建流程或停止执行该脚本。
